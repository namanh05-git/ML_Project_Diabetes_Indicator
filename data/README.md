# Data

`diabetes.csv` — 253,680 survey responses with 21 health and lifestyle indicators and a
3-class diabetes label. It matches the *Diabetes Health Indicators Dataset* on Kaggle, which
is derived from the CDC's 2015 Behavioral Risk Factor Surveillance System (BRFSS) survey.

Target column `Diabetes_012`: `0` = no diabetes, `1` = prediabetes, `2` = diabetes.

Class balance: 84.2% / 1.8% / 13.9%.

Check the original dataset's license on Kaggle before redistributing.
